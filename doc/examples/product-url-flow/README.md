# Product URL Flow Example

This example package is the canonical V1 sample for Agent Runtime.

Scenario:
- user provides a product URL
- system analyzes the product
- system generates a PRD
- user confirms PRD
- system generates a Todo List
- user confirms Todo
- executor runs multiple todo items in parallel
- system returns preview payload for frontend rendering

## Files

- `create-session.request.json`
- `create-session.response.json`
- `prd.example.json`
- `todo.example.json`
- `executions.example.json`
- `preview.example.json`
- `session.example.json`

These files are design-time examples for frontend/backend alignment.
